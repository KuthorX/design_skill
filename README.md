# design_skill

Agent skills for pushing AI-generated design past "design-by-committee" defaults.

| Skill | 用途 |
|---|---|
| [ai-design-quality](ai-design-quality/SKILL.md) | 探索 → 定义 → 交付 三阶段流程：种子多样性、大胆简报、独立评审子代理循环、图像/视频生成、删减与去 AI 味 |

## 安装

```bash
git clone git@github.com:KuthorX/design_skill.git
ln -s "$(pwd)/design_skill/ai-design-quality" ~/.claude/skills/ai-design-quality
```

## 来源

方法提炼自 Anshu Chimala 发表于 Lenny's Newsletter 的 *How to turn your AI into a world-class designer*（2026-09-01）。本仓库为个人学习整理，不含原文。
