# AI 设计质量提升（ai-design-quality）

## 核心认知

大模型按人类评分调优，默认倾向安全、共识的选择，结果是"终极设计委员会产物"：紫色渐变、左文右图、玻璃卡片。
好设计恰恰相反：从感受出发，做出乎意料的选择。
本 skill 用一套改编给 AI 代理的双钻流程，把模型推离最可预测的输出。

```
探索 Discover → 定义 Define → 交付 Deliver
  多方向、大胆   个性、评审循环   做减法、去 AI 味
```

**使用原则**：任何阶段都不要把 AI 的想法原样贴回 AI。人必须主动引导、记录反应、做选择。

---

## 阶段一：探索（Discover）

### 1. 随机种子注入多样性

直接要求"完全随机地做决策"无效：模型只会产出*听起来*随机、实际仍重复同一配色和结构的内容。模型本身不能随机行动。

正确做法（源自 Sakana AI 的 String Seed of Thought）：

1. 让代理先用 shell 生成一长串随机字母数字：
   ```bash
   LC_ALL=C tr -dc 'A-Za-z0-9' </dev/urandom | head -c 256; echo
   ```
2. 要求代理从字符串的规律中**推导**创意方向：配色、布局、字体、材质、隐喻。
3. 要求代理用专业判断把这个方向执行好。
4. 明确告诉代理：字符串只是灵感，**不得**在成品中出现或暗示。

提示词模板见 `references/prompts.md` 的「种子提示」。

### 2. 更有野心、更具体的简报

把你自己的品味当灵感源：一款游戏、一种室内风格、一个艺术装置。写法示例：

- 「每一屏像一张像素风游戏截图」
- 「整站是一座等距 3D 活城市，每个功能是一个街区」
- 「激进不对称布局、刺耳的配色与字体、让人不舒服的留白」

敢试听起来很糟的点子。如果你觉得"这不可能成"，往往方向对了。

### 3. 三步生成创意

1. **求广不求深**：要大量刻意浅层的高层点子。
2. **可视化并记录反应**：把喜欢的做成草图/截图，写下你的感受（哪个俗、哪个缺质感、哪个需要颜色），让 AI 按你的口味打磨。
3. **迭代后产出构建提示**：让 AI 写一份简洁的构建提示词，交给执行代理。

保留失败的提示词，在新模型上重测。

## 阶段二：定义（Define）

即使加了种子，设计仍可能停在"导航栏 + 左文右图 + CTA"的通用骨架。目标是给设计一个独立人格。

### 4. 独立评审子代理的正反馈循环

编码代理无法客观评审自己的作品。另起一个**设计评审子代理**，并遵守：

| 规则 | 做法 |
|---|---|
| 只看截图 | 评审只收到当前截图，不给代码、不给历史评价 |
| 全新上下文 | 每轮都在干净上下文中调用评审 |
| 大模型评审、小模型实现 | 评审用能力最强的模型，实现用小而强的模型 |
| 同一份评审提示 | 每轮复用完全相同的评审提示词 |
| 隐藏阈值 | 评审独立打到 9/10 以上才算完成，但不要告诉评审这个阈值 |
| 先验证收敛 | 先跑 1–2 轮看分数是否上升，否则代理会为无法满足的评审烧光 token |

评审每轮要做的事：

1. 识别设计试图达成的目标美学。
2. 想象顶级工作室会如何执行这一美学。
3. 列出当前作品与之的最大差距，兼顾整体构图与细节。
4. 惩罚过度堆砌和明显 AI 化的模式。
5. 给出紧凑、具体、大胆、有主见的反馈，并打 10 分制评分。

成本参考：评审通常只占总输出 token 的 10% 以下，比让大模型直接重做便宜约一半。

**评审标准要客观**：

- 差：「判断它美不美、像不像 AI 做的」
- 可：「对比顶级工作室会怎样执行」
- 最好：给 4 个专业案例加本次截图，让评审按精致度给 5 张排名

参考图只当基线和情绪板，不当复制对象。

执行流程、评审提示词见 `references/critic-loop.md`。

### 5. 图像生成注入个性

代理默认用渐变、几何形状和基础纹样，这是最明显的 AI 痕迹。要**明确提示**代理调用图像生成（它几乎不会主动用），可配合 shader / 3D，并在浏览器中逐帧核验。

密钥管理：给代理一个设有严格花费上限的专用 key，放在 gitignore 的 `.env.agents`，并在 `AGENTS.md` / `CLAUDE.md` 注明仅供开发、不得随产品发布。

### 6. 视频生成做动效

- 用聚合平台（如 fal.ai）一个 key 让代理自选当前最合适的模型。
- **循环动态图形**：在纯色背景上生成，再色键抠像或用视频抠图模型。玻璃/折射效果可先在页面背景色上渲染以"烘焙"折射，再抠掉背景。
- **状态过渡**：用两张产品静帧做关键帧插值，导航时播放或随滚动拖动。多段衔接时每段以上一段末帧为起点，优先选物理表现强的模型。

---

## 阶段三：交付（Deliver）

### 7. 删掉不增值的东西

AI 喜欢加，几乎不会减。过度解释、无目的的元素是 AI 作品的信号；克制才显高级。

典型需要删除的：装饰性光晕、随机文字颜色、冗余标签、比原生控件更差的自定义控件、多余容器与边框、没必要的渐变。

模型不会主动做减法，因为删除在它看来"有风险"。必须由你推动，直接下指令：「删掉所有不承担功能的元素，然后告诉我删了什么」。

### 8. 去除 AI 痕迹

对照 `references/ai-tells.md` 的清单逐项检查，让评审子代理专门跑一轮「找 AI 痕迹」。

---

## 快速检查清单

- [ ] 简报里有你自己的品味来源，而不是只有功能描述
- [ ] 用了种子字符串或同等的多样性机制
- [ ] 先求广、可视化、记录反应，再收敛
- [ ] 评审子代理独立、只看截图、大模型、同一提示、阈值不外泄
- [ ] 验证过评审分数在 1–2 轮内上升
- [ ] 明确要求过图像/视频生成而非默认渐变几何
- [ ] 做过一轮纯删减
- [ ] 跑过一轮 AI 痕迹排查
